# IIS + 护卫神主机大师部署说明

1. 在护卫神主机大师中创建站点，PHP版本选择 **PHP 8.0**，开启 `curl`、`gd`、`pdo_mysql`、`json`、`openssl`、`mbstring`。
2. MySQL 使用 5.7.44.0，预先创建空数据库并分配账号。
3. 将源码上传到站点根目录，确保 `config/` 对 IIS 应用池用户或 `IIS_IUSRS` 可写。
4. IIS URL Rewrite 模块需启用，根目录 `web.config` 已包含伪静态、REST API和安全响应头配置。
5. 访问 `/install/index.php` 完成环境检测、数据库连接测试、SQL初始化和管理员创建。
6. 生产环境必须绑定HTTPS证书；后台建议配合护卫神防火墙设置IP白名单。
7. API密钥在后台保存时使用AES-256-CBC加密；数据库备份文件请妥善保管。

## 后台操作手册
- 模型API配置中心：分别配置对话、图片、视频模型Key和Endpoint，并通过“测试”检查连通性。
- 会员管理：查看注册资料、封禁/解封、调整等级、手工充值积分。
- 调用日志：按模型筛选并导出CSV，用于审计和计费。
- 站点配置：维护展示样式、定价和合规提示；备份功能导出JSON数据。
